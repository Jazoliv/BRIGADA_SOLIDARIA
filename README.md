# Brigada Solidaria — Plataforma Web

Sitio web enfocado en la visibilización, gestión y coordinación de iniciativas de voluntariado y asistencia social. Desarrollado como proyecto académico grupal para la **Universidad de Buenos Aires (UBA)**.

## 🚀 Funcionalidades Principales

* **Sección Informativa e Impacto:** Presentación de causas sociales, metas de ayuda y proyectos comunitarios en curso.
* **Navegación e Interfaz Intuitiva:** Estructura web orientada a facilitar la participación ciudadana y el registro de voluntarios.
* **Diseño Responsivo:** Adaptación de la interfaz para una correcta visualización en dispositivos móviles y de escritorio.

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript
* **Control de Versiones y Trabajo Colaborativo:** Git, GitHub

## 👥 Trabajo en Equipo

Proyecto desarrollado de manera colaborativa aplicando buenas prácticas de control de versiones con Git (flujo de ramas, commits y resolución de conflictos en equipo).
